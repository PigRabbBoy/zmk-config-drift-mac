Drift V3 — คู่มือและตัวตรวจบอร์ด

เครื่องนี้ไม่น่าจะมีคีย์บอร์ดต่ออยู่

อ่านคู่มือได้ตามปกติ แต่โหมดทดสอบบอร์ดต้องเปิดบนเครื่องที่ Drift V3 ต่ออยู่จริง
กดปุ่มบนคีย์บอร์ดจริงแล้วปุ่มบนรูปจะสว่าง — ไม่นับคะแนน เพราะหน้าเว็บไม่มีทางรู้ว่า ZMK กำลังอยู่ layer ไหน เห็นแต่ผลลัพธ์ที่ออกมา อยากได้ตัวเลขที่เชื่อได้ให้ไปโหมดทดสอบบอร์ด
กด ⇧ Shift ค้างเพื่อดู legend ชั้นที่สอง

โหมดนี้ต้อง flash Test Firmware ก่อน ไม่งั้นตัวเลขไม่มีความหมาย

Production Firmware มี 4 ช่องที่ browser มองไม่เห็นเลย (encoder push ×2, lower, raise) และมี 3 คู่ที่ส่งค่าเหมือนกันจนแยกไม่ออก Test Firmware ทำให้ทั้ง 70 ช่อง + หมุน encoder 4 ทิศ ส่งค่าไม่ซ้ำกันเลย
  1. โหลด firmware.zip จาก GitHub Actions เอา drift_test_left / drift_test_right
  2. ต่อ USB-C → กด reset บน nice!nano 2 ครั้งเร็วๆ → drive NICENANO โผล่ → ลากไฟล์ลง ทำทั้งสองข้าง
  3. กดให้ครบทุกช่อง หมุน encoder ทั้งสองข้างทั้งสองทิศ
  4. flash drift_left / drift_right กลับ — อย่าทิ้ง Test Firmware ไว้บนบอร์ด
